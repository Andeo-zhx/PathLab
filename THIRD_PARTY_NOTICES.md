# Third-party notices

## Bundled fonts

The application bundles font assets and their license texts in each platform's `public/fonts` directory:

- Noto Serif SC subsets: SIL Open Font License 1.1, included as `OFL-NotoSerifSC.txt`.
- Allura Regular: SIL Open Font License 1.1, included as `Allura/OFL.txt`.

The application dependencies are not vendored in this repository. Install them from the platform-specific lockfiles; each upstream package retains its own license terms.
