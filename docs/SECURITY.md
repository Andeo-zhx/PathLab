# Security and private data

Please do not publish API keys, signing certificates, passwords, real patient images, or `.pathlab` project files in this repository or in public issue reports.

If you find a security issue, use GitHub's private vulnerability reporting for this repository when available. If it is unavailable, open an issue without including credentials, private project files, or medical images; describe how the maintainers can contact you through GitHub.

If a credential is exposed, revoke or rotate it immediately. Removing it from the latest commit is not enough because Git history and clones can retain the value.
