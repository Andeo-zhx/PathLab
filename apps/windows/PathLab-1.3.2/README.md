# PathLab · 病理实验图文标注工作台

**PC Electron 1.3.2** · Windows x64

为病理实验报告设计的**轻量、本地化、低门槛**图文工作台。核心不是通用图像编辑，而是把
「放图 → 排图 → 标注 → 局部放大 → 写观察描述 → 导出报告素材」做得极其顺手。

> 软件只帮助呈现观察结果，**不做自动病理诊断**，不识别病变结构，不给出 AI 结论。

---

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建（dist/）
npm run preview    # 预览生产构建
npm run desktop    # 在 Electron 中启动 PathLab 1.3.2
npm run package:portable # 构建 Windows 便携版
```

浏览器开发模式可用于普通标注。桌面版的标注翻译统一使用 DeepSeek Chat Completions API；点击发送或「保存并翻译」后，当前标注文字会发给 DeepSeek。图片与 `.pathlab` 工程保存在本机，API Key 使用 Electron `safeStorage` 加密保存。

## 已实现的功能

### 画布与图片
- 拖拽 / 文件选择器 / 剪贴板粘贴导入 JPG · PNG · WEBP · GIF · BMP · AVIF
- 图片自由拖动、四角等比缩放（Alt 取消等比）、旋转 90°、复制、锁定、置顶 / 置底
- 大图交互显示使用降采样副本，裁切和圆形放大保持原图像素坐标映射
- 双击图片进入**裁切模式**（完整图 + 压暗遮罩 + 8 个控制点，Enter 完成 / Esc 取消）
- 多选后一键**垂直 / 水平 / 网格排列**（间距 22px）
- 拖动时与其它图片**边缘 / 中线对齐吸附**并显示参考线
- 画布缩放 10%–800%：滚轮缩放、Shift+滚轮横向平移、Space 拖动平移、`⌘0` 适应全部、`⌘1` 实际大小

### 标注（全部是独立矢量对象，不烧录进原图）

| 工具 | 快捷键 | 说明 |
|---|---|---|
| 选择 / 移动 | `V` | 框选、多选、拖动、缩放、对齐吸附 |
| 矩形 | `R` | 描边色 / 线宽 / 虚实 / 极淡填充 |
| 椭圆 | `O` | 按住 Shift 强制正圆 |
| 多边形套索 | `P` | 连续单击加点，**双击 / Enter / 右键**闭合，可拖动节点 |
| 自由轮廓 | `F` | 自由绘制，结束后 Douglas–Peucker 简化 + Chaikin 平滑 |
| 箭头 | `A` | 默认 3px，选中后可拖两个端点 |
| 直线 | `L` | 同上 |
| 文字 | `T` | 中英文、字号、字重、颜色、对齐、可选极淡背景与描边；设置中可指定中英文默认字体与默认字号 |

所有标注可再次选中、移动、缩放、改色、复制、删除、锁定。
标注颜色默认病理红 `#E23B3B`，自动记忆最近 4 种颜色。

### 圆形放大引用（重点功能）

语义是"**真放大镜**"：圈选区（ROI）是唯一真相，投射圆是它的放大副本。

1. 选 `M`，在图片上拖出圆形 ROI（拖出来的虚线圆就是最终圈选区，所见即所得）；
2. 松开后在 ROI 附近自动生成投射圆，默认 2.0×；
3. 满足两条由构造保证的不变式：
   - **投射圆直径 = 圈选区在画布上的直径 × 倍率**（2× 就是圈选图的 2 倍，不是"圆多大就装多大范围"）；
   - **投射圆里看到的就是圈选区本身**（所见即所圈）；
4. 拖投射圆右边缘 = **改取景范围**：圈选区与投射圆一起缩放，倍率不变；也可以直接在原图上拖圈选区边缘；
5. 拖本体只移动投射圆；浮条里可调倍率、**圈选虚线框颜色（调色板直选）**、投射圆边框颜色、连接线开关；
6. 圈选区虚线框为三层绘制（白色光晕 + 高对比虚线 + 极淡填充），线宽按屏幕像素换算，任何缩放下都清晰；
   圈选区被限制在图片有效像素内，不会投射出空白；
7. ROI 与放大镜**始终绑定**：移动 / 缩放 / 裁切 / 旋转源图，ROI、连接线、放大内容同步跟随；
8. **导出时用原始像素重新采样**，不是截屏，任意倍率都保持锐利。

> 旧工程（v1）打开时按 `sourceRegion` 为准重新推导投射圆半径（见 `src/lib/migrate.ts`）。

### 撤销 / 重做 / 剪贴板
- `⌘Z` / `⌘⇧Z` 覆盖导入、排版、绘制、移动、缩放、裁切、层级、锁定等全部主要操作
- `⌘C` / `⌘V` 复制粘贴对象；`⌘V` 在对象剪贴板为空时尝试粘贴剪贴板图片
- `⌘D` 复制并偏移；`Delete` 删除；`⌘A` 全选

### 右侧观察记录
- Tiptap 大号写作区（正文 18px / 行高 1.72），支持段落、H1/H2、粗体、斜体、项目符号、编号列表
- 选中文字后出现浮动格式条；`⌘B` / `⌘I` 等原生快捷键
- 顶部「插入」菜单提供**结构块模板**：切片描述（低倍/高倍）、大体描述（整体/病灶）、病理诊断、讨论
- 粘贴自动转纯文本，不引入外部网页样式
- 窗口宽度 < 980px 时自动收起为可展开抽屉

### 工程与导出
- `⌘S` 保存为 `.pathlab`（ZIP 容器：`project.json` + `assets/*` 原始二进制）
- IndexedDB 自动保存草稿（900ms 防抖），异常关闭后重新打开自动恢复
- 导出弹窗（极简）：
  - **导出画布**：PNG，1× / 2× / 4× / 6× / 8×，白色或透明背景，并显示分辨率与预计文件大小
  - **整页图文**：A4 纵向或自适应长图，含工程标题、图像与标注、富文本记录
- 所有矢量在导出时**以目标分辨率重新渲染**（Konva 离屏 Stage + `pixelRatio`），文字 / 箭头 / 圆圈边缘保持锐利

### 双语翻译（桌面版 1.3.2）
- 单选未锁定文字标注后点击「翻译」；中文自动译为英文，其他文本自动译为中文。
- 翻译使用 DeepSeek `deepseek-flash`，通过 Chat Completions API 请求，并关闭 thinking 模式。
- 打开翻译对话框不会发送原文；点击「发送至 DeepSeek 翻译」后才提交当前标注文字。
- 译文先在预览框中显示，可直接修改；确认后追加到原文下一行，位置和样式不变，且作为一次编辑支持撤销。
- API Key 通过 Electron `safeStorage` 加密保存在本机，支持更新和删除。

### 1.3.2 跨版本数据与稳定性
- 导入图片和切换工程采用分阶段提交；遇到解码失败时不留下半成品，连续操作时避免旧任务覆盖当前工程。
- 自动保存按顺序写入；启动恢复会验证草稿结构，`.pathlab` 打开会先校验项目和资源再提交，避免部分导入。
- `.pathlab` 保持原有 ZIP 结构与 version 2 schema；没有 iOS 专属字段，也不要求旧项目迁移。
- 超过显示阈值的大图使用降采样交互副本；裁切和放大引用分别将原图坐标换算到实际显示/导出位图，减少高清图偏移。
- 旧版仍沿用独立的 Electron 应用标识和数据目录。本构建版本的应用标识为 `local.pathlab.desktop.v132`，用户数据目录为 `%APPDATA%\PathLab-1.3.2`。

## 技术栈与结构

React 19 · TypeScript · Vite · Konva / react-konva · Zustand + Immer · Tiptap · Dexie · JSZip · Lucide

```
src/
  canvas/           画布引擎（手工命中测试 + 单一手势状态机）
    CanvasWorkspace.tsx   舞台、指针状态机、快捷键、拖放
    ImageNode.tsx         图片卡片 + 裁切视图 + 宿主标注组
    AnnotationShape.tsx   矩形/椭圆/多边形/自由轮廓/箭头/直线/文字
    MagnifierNode.tsx     圆形放大引用（clipFunc + 原始像素映射）
    OverlayLayer.tsx      选中轮廓、控制点、草稿预览、参考线、连接线
    hitTest.ts            自顶向下命中测试（旋转 / 缩放安全）
    handles.ts            控制点计算（含旋转后的方向光标）
    transform.ts          旋转图片的等比缩放数学
    TextEditOverlay.tsx   画布上文字编辑用的 HTML 输入层
  components/       顶栏、工具栏、选中浮条、写作区、导出、菜单、提示
  store/            工程文档 + 历史（Zustand/Immer）、UI 状态、样式记忆、自动保存
  lib/              几何、图像资源、富文本排版、导出布局、工程打包、平台差异
  styles/           设计令牌 + 组件样式（原生 CSS）
```

### 几个关键设计决定
- **手工命中测试取代 Konva 命中图**：画布所有图层 `listening={false}`，指针事件自己判定
  「控制点 → 标注 → 放大引用 → 图片」，避免拖拽 / 变换器的边界行为。
- **标注挂在宿主图片的变换组里**：几何以源图像素存储，因此移动 / 缩放 / 裁切 / 旋转图片时
  标注自然跟随；线宽与字号按当前显示比例换算回世界单位。
- **世界单位 vs 屏幕单位**：标注尺寸以「世界像素」持久化，新建时按当前画布缩放做有上限的
  屏幕补偿，保证「画出来的粗细 = 看到的粗细」，同时导出时仍与图像成比例。
- **历史快照只存几何**：位图放在资源表（内存 + IndexedDB / ZIP），历史栈只保存不可变数组引用，
  因此撤销极轻量。
- **文字文档独立订阅**：画布订阅 `images / annotations / magnifiers / canvas`，右侧打字不会重绘画布。

## 自动化验收

仓库内附带两套基于本机 Chrome 的端到端验收脚本：

```bash
npm run dev           # 先在 5199 端口启动
npm run verify        # 40 项：导入/绘制/绑定/撤销/裁切/导出/工程往返/自动恢复
npm run verify:ui     # 13 项：菜单/快捷键面板/浮条加粗/刷新恢复/导出/窄屏抽屉
```

脚本指向本机安装的 Chrome（可用 `CHROME_PATH` 覆盖），截图输出到 `verify-out/`。
